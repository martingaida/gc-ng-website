# Constitution

This project is a public website. Agents follow `AGENTS.md`.

- `specs/` is the source of truth when it conflicts with code.
- Visual language is locked in `.tastemaker/style-lock.md` once written.
- SEO and AEO requirements in `AGENTS.md` are mandatory for public routes.
- Skills under `skills/` are consulted by trigger, not loaded wholesale.
- The UI stack is React, Vite, TypeScript, Tailwind, and shadcn/Radix wrappers in `src/ui`.
- Do not add SkillSpector unless the repository owners explicitly request it.
